## 📖 项目定位

**源智 HR** 不是传统的人事管理系统，而是一个**多 Agent 团队驱动的智能人力运营操作系统**。

它彻底颠覆了传统 HR 软件的「人操作软件」模式，构建了一套完整的虚拟 HR 部门——HR 总监 + 6 大专业团队 + 21 个执行 Agent，自动完成 80% 的 HR 事务工作。

### 🔥 核心差异

| 对比项 | 传统人事系统 | 源智 HR |
|--------|-------------|---------|
| 产品形态 | 纯流程工具，只做录入审批 | AI 虚拟 HR 团队，自动干活 |
| AI 能力 | 单点问答，无专业深度 | 多 Agent 团队协作，专业 HR 能力 |
| 模型绑定 | 厂商绑定，收费贵 | 用户自托管 Key，全模型兼容 |
| 数据隐私 | 数据上传云端 | 100% 本地私有化部署 |
| 系统扩展 | 固定功能，无法扩展 | 微内核插件化，无限扩展 |
| 权限体系 | 粗糙，无数据隔离 | 四层精细化权限，字段级脱敏 |

## 🏆 九大核心创新（真正的护城河）

### 创新 1：行业首个「多 Agent 虚拟 HR 团队架构」

传统系统：人操作软件
本系统：AI 团队自动干活

- HR 总监 Agent 全局调度，自动拆解任务
- 6 大专业团队完全对标真实 HR 部门分工
- 21 个执行 Agent 实现真正的无人化 HR 运营
- 竞品全部是「单点 AI 功能」，我们是「完整 AI 部门」

### 创新 2：用户自托管 AI 密钥，零官方成本

- 所有大模型 Key 用户自己填，官方永久零 API 成本
- 支持 OpenAI / 豆包 / DeepSeek / 通义千问 / 智谱 / Kimi
- 所有请求本地发出、数据不出企业、无第三方中转
- 智能识别厂商：粘贴 Key 自动判断模型、自动填地址

### 创新 3：HR 专业领域引擎 + 合规引擎

- 内置全国劳动法、社保、个税、产假、加班合规规则库
- 内置岗位胜任力模型、人才盘点模型、薪酬带宽模型
- AI 输出必须经过专业规则校验，杜绝幻觉

### 创新 4：组织记忆数据飞轮

- 自动学习企业自己的管理风格
- 自动学习高绩效员工特征
- 自动学习部门绩效打分习惯
- 自动识别离职风险行为模式
- **越用越精准、迁移成本极高**

### 创新 5：微内核插件化操作系统级架构

- 核心极简稳定，所有业务全部插件化
- 社区可无限扩展模型、功能、行业模板
- 官方内置插件开箱即用，开发者可按规范扩展

### 创新 6：企业级四层精细化权限体系

- 菜单权限 + 数据行权限 + 字段级脱敏权限 + Agent 调用权限
- 支持薪资双盲、敏感数据隔离、角色完全隔离
- 满足政企、大厂安全标准

### 创新 7：全角色数据下钻可视化大屏

- 老板经营大屏 / HR 业务大屏 / 部门管理大屏 / 员工自助看板
- 全部支持逐层下钻、溯源、AI 自动分析报告

### 创新 8：全生命周期业务数据自动流转闭环

- 从招聘 → 入职 → 培训 → 绩效 → 薪酬 → 离职 → 组织沉淀
- 全链路自动同步、无需人工重复录入

### 创新 9：开源无后门、可商用、可私有化部署

- 纯本地部署、无数据上传、无后台后门、无强制联网
- 可完全离线使用
- 非常适合政府、军工、工厂、涉密企业

## 🚀 快速开始

### 环境要求

- Python 3.11+
- Node.js 18+

### 1. 克隆项目

```bash
git clone https://github.com/你的用户名/yuanzhi-hr.git
cd yuanzhi-hr
```

### 2. 启动后端

```bash
cd backend
pip install -r requirements.txt
python run.py
```

后端运行在 http://127.0.0.1:8001

### 3. 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端运行在 http://127.0.0.1:5174

### 4. 登录系统

- 默认账号：`admin`
- 默认密码：`admin123`

### 5. 配置 AI 模型

进入「AI 能力 → 模型配置」，粘贴你的 API Key，系统会自动识别厂商并填好配置，点击「测试连接」验证通过后保存即可。
